# קטלוג ותמחור

הקטלוג נמצא ב-[lib/catalog.ts](../lib/catalog.ts), וחישוב המחיר ב-[lib/pricing.ts](../lib/pricing.ts).

## כלל התמחור

- **מחיר לרצועה:** העלות כפול 2, מעוגלת למעלה לסכום שנגמר ב-9. המינימום הוא ₪19.
- **מחיר לזוג:** 10% הנחה על שתי רצועות, מעוגל למטה לסכום שנגמר ב-9. זו ההנחה היחידה באתר, והיא אמיתית.
- **כמות אי-זוגית:** כל זוג במחיר הזוג, והרצועה הנותרת במחיר רגיל.

"עלות" היא מה שמשלמים בעגלה של אלי אקספרס על רצועה אחת, כולל המשלוח לכתובת של הלקוח. כשמעדכנים עלות בקובץ, המחיר באתר, בתקנון ובהודעת הוואטסאפ מתעדכן לבד.

## מה לבדוק מול כל מוכר לפני שמוסיפים קישור

1. **מחיר בעגלה,** כולל משלוח לישראל, לרצועה אחת ולשתיים.
2. **מידות:** אילו מידות המוכר מציע בפועל. את Apple Watch מחלקים לשתי קבוצות:
   - **קטנה:** 38, 40, 41 מ״מ, וגם 42 מ״מ של סדרה 10 ואילך.
   - **גדולה:** 42 מ״מ של סדרות 1–3, וגם 44, 45, 46, 49 מ״מ.
3. **צבעים** שקיימים במלאי. ברשימה באתר מופיעים רק צבעים שהמוכר באמת מציע.
4. **זמן משלוח** לישראל. באתר כתוב 10–14 ימי עסקים.
5. **ביקורות עם תמונות** של קונים, כדי לראות את האיכות האמיתית.

## איך מעדכנים מוצר

1. ב-[lib/catalog.ts](../lib/catalog.ts) מעדכנים `cost`, `sourceUrl`, `colors` ו-`sizes`, ומסמנים `costVerified: true`.
2. אם נוסף מוצר או צבע, מרנדרים מחדש את תמונות הגלריה:
   ```bash
   npm run build && npx next start -p 3200
   node scripts/render-products.mjs http://localhost:3200   # בטרמינל אחר
   ```
3. כשמגיעות תמונות אמיתיות מהדגימות, הן מחליפות את ההדמיות (`public/renders`).
